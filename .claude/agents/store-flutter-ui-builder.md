## Rules
- Imports: `package:store/core/ui/kit/app_kit.dart` and `import 'package:flutter/widgets.dart' as fw;`. NEVER import `material.dart` directly (the kit re-exports it); NEVER add a third-party UI kit.
- kit `IconButton` takes `variance:` (`ButtonVariance.ghost`…). Prefer `PrimaryButton`, `SecondaryButton`, `OutlineButton`, `DestructiveButton` from the kit.
- **Look = "Ink & Ember" (light + dark): FLAT paper/ink cards (radius 16) with a Line hairline + soft shadow, ONE Ember accent (`#F2622A`) for primary buttons/CTAs/active nav/selected state, outline-style icons, ink pill bottom nav with a filled-ember active circle; tokens are non-const getters that follow the active theme.** No glass, no violet, no multi-color gradients. Never hardcode colors; use `AppDesignTokens` (`primaryColor`=Ember, `blushColor`=promo/status TAG only, `successColor`, `warningColor`, `dangerColor`, `infoColor`, `hairline`, `cardColor`, `mutedSurfaceColor`, `onAccentColor`). Cards = `AppCard`/`StatCard`/`MenuTile`/`EntityListCard`; icon chips = `AppIconChip`; badges = `StatusBadge`; promo/editorial banner = `AppPromoBanner`. Serif-italic display (`AppDesignTokens.displayFontFamily` + `displayFontFamilyFallback`, NOT bundled) is for promo/editorial headlines ONLY; prices/tabular numbers use `AppDesignTokens.tabularFigures`.
- **Elevation:** lift cards with `AppCard(elevated: true)` (or `EntityListCard`, elevated by default) — one shared lifted shadow (`AppDesignTokens.elevatedShadow()`); never pass an ad-hoc `boxShadow`. Flat hairline-only cards are for dense/nested content; primary list rows, KPI cards and menu rows are `elevated`.
- **Motion:** entrances via `FadeSlideIn(index:)` (or `animationIndex:` on `EntityListCard`/`StatCard`/`MenuTile`), press feedback via `PressScale`, KPI numbers via `CountUpText`, live indicators via `PulseDot` (all in `design_system/app_motion.dart`). No new animation packages.
- Layout via design system: `AppHeader`, `AppCard`, `EntityListCard`, `AppDesignTokens` spacing/radius/colors from `lib/core/ui/shadcn/widget/design_system/`. No raw hex colors, no magic font sizes - use theme typography.
- Data: `PaginationList<…>` for lists, `GetModel<…>` for details, `CreateModel<…>` for submits. Capture the cubit via `onCubitCreated` when you need to reload; make list screens `StatefulWidget` only to hold that reference.
- **Loading skeletons = "calm silhouette" (design-approved).** Keep the real card's SHELL (same elevation/shadow/radius/hairline as the `AppCard`/`EntityListCard` it previews) but reduce the content INSIDE to just a leading icon/image box + two neutral shimmer lines (a wider "title" line, a shorter "subtitle" line). Do NOT reconstruct real fields: no faux chips, badges, status pills, metric tiles or nested bordered boxes. Shared skeletons live in `app_skeleton_loader.dart`: `_CalmCardContent`/`_CalmLine` are the shared building blocks; `ProductCardSkeleton`/`CategoryCardSkeleton` (80x80 image box), `ProductVariantCardSkeleton`, `OrderCardSkeleton`, `InventoryMovementCardSkeleton` (elevated shells); `ReportSkeleton` (KPI silhouettes + a chart block + calm lines); `SelectorItemSkeleton` (flat selector tiles); `DetailSkeleton` (hero line + elevated section cards); `ListSkeleton` (generic elevated image-row default). A shared abstraction is not required — write a screen-local bespoke skeleton in the SAME calm language (e.g. dashboard's ink hero + floating KPI/menu silhouettes, top-sellers' rank box + two lines) when it gives a closer match. Pass it via `loading:`/`loadingWidget:`; `GetModel` falls back to `DetailSkeleton` when none is given.
- Navigation: `fw.Navigator.push(fw.PageRouteBuilder(... transitionDuration: Duration.zero ...))`; `await` it and reload the caller afterwards.
- Destructive/irreversible actions: `showConfirmDialog` + `runRemoteAction` from `lib/core/ui/dialogs/action_helpers.dart`; show errors with `Dialogs.showSnackBar`.
- Forms: state in the cubit (no `setState` for form/validation/loading). Local controllers inside dialogs are fine.
- **Pickers / multi-select flows:** short confirm/edit prompts stay `AlertDialog`; a scrollable *browse-and-pick-many* flow uses a scroll-controlled modal bottom sheet, not a fixed-size `AlertDialog` (fixed `SizedBox` widths clip on real phones). Pattern: `showModalBottomSheet(isScrollControlled: true, backgroundColor: transparent, ...)` wrapping a `BlocProvider<…Cubit>`, content in a `FractionallySizedBox(heightFactor: ~0.92)` with a drag handle + header close `✕`, a scrollable body (filter chips + `PaginationList`), and a pinned footer (summary + primary CTA). Dismiss via drag-down / close icon (no redundant Cancel button). Reference: `features/order/screen/widgets/add_product_dialog.dart` (`AddProductDialog.show(...)`, "catalog + tray" that stages lines then commits one awaited `onItemAdded` call per line).
- RTL-safe: use `EdgeInsetsDirectional`, `AlignmentDirectional`, no hard-coded left/right.
- Accessibility: tap targets >= 44dp, labels for icon-only buttons.
- New text -> `.tr()` keys (hand to `store-flutter-localizer`; do not leave new hardcoded literals).
- Placeholder buttons that do nothing are forbidden: wire them or remove them.
- **Permission-gated UI:** hide tabs/tiles the user can't access with `context.read<AuthCubit>().can('<ABP.Policy>')`; never crash on 403 - let `GetModel`/`PaginationList` show their error widget. See `features/reports/screen/reports_screen.dart`.
- **No chart package exists and none may be added.** Build charts from token widgets (see `ReportBarChart` in `features/reports/.../report_widgets.dart`). Date-range pickers use `showDatePicker` (exported via `app_kit.dart`) and must enforce `ToDate >= FromDate` client-side (`ReportDateRangeBar`).
- Backend enum ints that arrive raw (not `{id,name}`) must be mapped to `.tr()` labels in the UI, never shown as raw English (see report enum-label helpers).
- **Hero + floating/overlap layouts:** an ink hero (`AppDesignTokens.navBackgroundColor` + a low-opacity `ember`-over-ink `RadialGradient`, bottom radius 26) with content floating/overlapping its lower edge via `fw.Transform.translate` / `fw.Positioned`. References: `features/home/screen/dashboard_screen.dart` (ink hero with a serif-italic headline KPI + a `CustomPaint` stock-health ring, floating `AppCard` KPIs with a stronger shadow, and a grouped elevated-row menu with ember count badges) and `features/auth/screen/login_screen_shadcn.dart` (ink hero + white/dark sheet with a large top radius). On-ink text uses `onAccentColor`/`navMutedColor`, never the theme text token. A bespoke `CustomPaint` ring/gauge is allowed (no chart package) — stroke it with the Ember tokens via `SweepGradient`.
